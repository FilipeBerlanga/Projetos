## 📌 Descrição do Projeto

Este projeto apresenta um **portal de entretenimento digital** em formato de página web estática. Ele reúne três categorias principais:

- **Filmes e Séries**
- **Música e Podcasts**
- **Games e Tecnologia**

O objetivo é demonstrar a construção de uma interface de entretenimento usando apenas **HTML5** e **CSS3**, com foco em organização de conteúdo e apresentação visual.

## 🧱 Estrutura do Projeto

- `Filipe_Berlanga_Ag13_DS_I.html` — arquivo principal com a estrutura do portal
- `estilo.css` — arquivos de estilo que definem cores, layout, cards e responsividade básica
- `reset.css` — arquivo de reset básico para normalizar margens e estilos do navegador
- `README.md` — documentação do projeto

## 🎯 Funcionalidades Principais

- Layout dividido em seções com conteúdo próprio para cada categoria
- Uso de **cards** (`.card-entretenimento`) para separar visualmente as áreas
- Imagens de destaque para cada categoria, incluindo links visuais a filmes, músicas e jogos
- Estilo escuro com contraste em branco e azul para sensação de portal digital
- Elementos responsivos usando unidade relativa (`vw`) para imagens e largura de cards

## 🎨 Tecnologias Utilizadas

- **HTML5** — marcação semântica e estrutura da página
- **CSS3** — estilização visual, layout flexbox e design de cards

## 🚀 Como Executar

1. Clone o repositório ou copie a pasta do projeto.
2. Abra o arquivo `Filipe_Berlanga_Ag13_DS_I.html` em um navegador web moderno.
3. A página abrirá automaticamente com o portal de entretenimento.

> Dica: para melhor visualização, use um navegador atualizado como Chrome, Firefox ou Edge.

## 💡 Observações

- O projeto foi feito para fins de estudo e demonstração de criação de interfaces estáticas.
- A página não possui funcionalidade dinâmica em JavaScript — todo o conteúdo é exibido diretamente via HTML e CSS.
