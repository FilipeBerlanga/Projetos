## Visão geral

Projeto de apresentação turística da cidade de Marília, desenvolvido em HTML e CSS. O site destaca atrativos históricos, culturais, naturais, esportivos e de entretenimento da cidade, com imagens ilustrativas e links para localização no Google Maps.

## Arquivos principais

- `Filipe_Berlanga_Ag14_DS_I.html` - página principal do projeto.
- `estilo.css` - estilo visual personalizado da página.
- `reset.css` - normalização básica de estilos para garantir consistência entre navegadores.

## Funcionalidades

- Conteúdo organizado em seções temáticas: História e Ciência, Natureza e Lazer ao Ar Livre, Educação e Esporte, Gastronomia e Vida Noturna.
- Cada atração conta com imagem de destaque e link para o mapa do Google Maps.
- Layout responsivo baseado em CSS para melhor apresentação.

## Como usar

1. Abra a pasta do projeto.
2. Abra o arquivo `Filipe_Berlanga_Ag14_DS_I.html` em um navegador.
3. Navegue pelas seções e clique nas imagens para obter a localização no Google Maps.

## Padrões adotados

- Estrutura semântica com `main`, `section`, `article` e `header`.
- Uso de CSS externo para separar conteúdo e estilo.
- Links externos configurados para abrir em nova aba com `target="_blank"` e `rel="noopener noreferrer"`.

## Possíveis melhorias

- Adicionar navegação fixa para pular entre seções.
- Incluir um mapa interativo embutido na página.
- Melhorar a acessibilidade com descrições e contrastes de cores adicionais.
- Tornar o layout 100% responsivo para dispositivos móveis.
