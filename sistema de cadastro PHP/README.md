Projeto simples em PHP para demonstração de cadastro de usuários.

Descrição
- Este repositório contém um formulário de cadastro (`cadastro.html`) e um script PHP (`processaCadastro.php`) que processa os dados enviados pelo formulário.
- Objetivo: exemplificar um fluxo básico de submissão de formulário e processamento server-side usando XAMPP/Apache + PHP.

Como usar
1. Coloque a pasta do projeto dentro de `htdocs` do XAMPP (ex.: `C:\xampp\htdocs\Desenvolvimento-sistema\DS2_AG2`).
2. Inicie o Apache pelo painel do XAMPP.
3. Acesse `http://localhost/Desenvolvimento-sistema/DS2_AG2/cadastro.html` no navegador.

Arquivos principais
- cadastro.html: formulário HTML de exemplo.
- processaCadastro.php: recebe os dados do formulário e os processa (ex.: validação, salvamento).
